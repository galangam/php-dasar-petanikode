# 🐘 PHP Dasar Petani Kode

Repo ini berisi **kumpulan latihan PHP dasar** berdasarkan tutorial dari [Petani Kode](https://www.petanikode.com/php/).  
Tujuannya untuk memahami dasar-dasar pemrograman PHP seperti sintaks, variabel, operator, percabangan, perulangan, array, dan fungsi.

## 🧠 Tujuan Belajar
- Memahami dasar logika pemrograman dengan PHP  
- Menulis kode PHP dengan struktur yang benar  
- Menjalankan kode di web server lokal seperti XAMPP  
- Mempersiapkan diri untuk mempelajari PHP tingkat lanjut (OOP, Database, Framework)

---

## ⚙️ Cara Menjalankan
1. Pastikan sudah menginstal **XAMPP** atau server lokal lainnya  
2. Simpan folder proyek ini di dalam direktori `htdocs`  
3. Jalankan **Apache** di XAMPP Control Panel  
4. Akses di browser melalui:  
http://localhost/php-dasar-petanikode/
